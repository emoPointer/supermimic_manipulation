# SuperMimic 与 PPO 对比及消融实验报告

数据截至 2026-10-30 · emoPointer

BoxInBin、Lemon、MugHang 三个任务上，SuperMimic 达到 80% 测试成功率所需的环境步数约为 PPO 的
1/3 到 1/10，单卡训练时间与 PPO 相当（1.0–2.9 小时对 1.0–4.5 小时；本项目的训练代码和整体流程都
没有专门做速度优化：收集数据、拟合世界模型和改进策略三步本可以并行，本项目里是按顺序执行的）。
Square 只有 SuperMimic 学会（两个种子 94% 和 95%，PPO 12%）；Drawer 上 PPO 更好（100% 对 76% 和
90%）。在消融实验中，只从完整任务起点训练（去掉 reset 类别）后，10 个 run 里有 7 个低于 30%。

## 实验设置

- **任务与种子**：五个仿真 ARX5 机械臂任务，每种方法、每个任务 2 个随机种子。
- **共用设定**：两种方法用同一个训练 reset bank；PPO 的奖励就是 SuperMimic 在想象中用的那套
  奖励。PPO 的环境步数上限是 20 亿步，所有类别都达到 90% 或评估进入平台期就提前停止。
- **Square 和 Drawer 的 SuperMimic**：用合并后的代码重训（见[最后一节](#square-训练调度与-drawer-复现)）。
  Square 从头训练，余弦学习率调度覆盖 20,000 轮：s1 在第 16,200 轮所有类别都超过 90% 后停止，
  s0 训满 20,000 轮。Drawer 按 README 的配方训练 10,000 轮。
- **评估**：确定性策略、完整回合。测试 bank 与训练 bank 用不同的随机种子和划分采集，每个 reset
  类别 64 回合，成功率取各类别的平均。
- **选 checkpoint**：每个 run 取训练 bank 上（每类 32 回合）成功率最高的 checkpoint（并列时取
  较早的），报告它在测试 bank 上的成功率。候选是 SuperMimic 每 2,000 轮加最后一个，PPO 每个
  评估过的 checkpoint。
- **步数与时间**：环境步数是真实仿真转移数，SuperMimic 每轮 10,240 条，PPO 每轮 24,576 个环境
  （MugHang 16,384）× 32 步。时间 = 迭代数 × 单独占用一张 A100 时测得的每轮耗时（SuperMimic
  1.2–2.6 秒，PPO 14–101 秒），不含启动和评估。

## 对比汇总

成功率上 SuperMimic 在 BoxInBin、Lemon、Square 高于 PPO，MugHang 两者相近（97% 对 98–100%），
Drawer 落后。每格是 s0 / s1。

| 任务 | SuperMimic 成功率 | PPO 成功率 | SuperMimic 到 80% 的步数（百万） | PPO 到 80% 的步数（百万） | SuperMimic 到 80% 的时间（小时） | PPO 到 80% 的时间（小时） |
| --- | --- | --- | --- | --- | --- | --- |
| BoxInBin | 97% / 94% | 96% / 88% | 31 / 31 | 201 / 201 | 1.1 / 1.1 | 1.0 / 1.0 |
| Lemon | 100% / 100% | 99% / 94% | 31 / 31 | 302 / 201 | 1.0 / 1.0 | 1.8 / 1.2 |
| MugHang | 97% / 97% | 100% / 98% | 62 / 31 | 201 / 302 | 2.9 / 1.4 | 3.0 / 4.5 |
| Square | 94% / 95% | 12% / 12% | 82 / 82 | 未达到 / 未达到 | 5.4 / 5.4 | 未达到 / 未达到 |
| Drawer | 76% / 90% | 100% / 100% | 未达到 / 41 | 101 / 101 | 未达到 / 2.9 | 3.6 / 3.6 |

- 成功率是按训练 bank 选出的 checkpoint 在测试 bank 上的成功率。“未达到”指整个训练中测试成功率
  从未到 80%。
- 到 80% 的步数取第一个达标的评估点。PPO 只在第 32、64、128、256、384… 轮评估，所以它的数字是
  上界：BoxInBin 在 1 亿步时还是 44% / 46%。
- PPO 在 BoxInBin 上 2 亿步时达到 96% / 88%，之后两个种子都退化到 0%（12 亿步）。选 checkpoint
  的规则选到的是退化前的那个。
- Drawer 的 SuperMimic s0 在相邻 checkpoint 之间波动很大：测试成功率在第 4,000、6,000、8,000、
  10,000 轮依次是 78%、24%、76%、69%；s1 稳定得多（90%、90%、85%、88%）。

## 消融：去掉 reset 类别

![完整方法与只从完整任务起点训练](media/ablation_reset_categories.png)

| 任务 | 完整方法（s0 / s1） | 只从完整任务起点训练（s0 / s1） |
| --- | --- | --- |
| BoxInBin | 97% / 94% | 15% / 58% |
| Lemon | 100% / 100% | 25% / 99% |
| MugHang | 97% / 97% | 25% / 25% |
| Square | 94% / 95% | 10% / 9% |
| Drawer | 76% / 90% | 65% / 8% |

按训练 bank 选出的 checkpoint，测试 bank 每类 64 回合。

去掉 reset 类别后，只有 Lemon s1（99%）和 Drawer s0（65%）接近完整方法。MugHang 两个种子和
Lemon s0 都停在 25%，只在最后一类（离目标最近的起点）上成功。Square 和 Drawer 的消融 run 是在
重训之前跑的，Square 的消融用的是默认的 10,000 轮学习率调度；完整方法在同样的调度下第 10,000 轮
是 67% 和 68%，仍远高于消融的 10% 左右。

## Square 测试 bank 修正

修正后 PPO 和消融在 Square 上的成功率都减半，SuperMimic 变化不大。Square 训练用的 bank 里，第 3 类
（部分套入）是停在柱子旁、柱子上方、已套上三种状态各占三分之一；原来的测试 bank 和选 checkpoint
用的 bank 里，第 3 类只有已套上。两者现在都换成按训练 bank 比例混合的新 bank（测试 bank 每类
255 个，三种状态各 85 个），本文的 Square 数字都来自新 bank。

| 方法 | 原 bank（s0 / s1） | 新 bank（s0 / s1） |
| --- | --- | --- |
| SuperMimic（重训之前的续训 run） | 78% / 97% | 73% / 95% |
| PPO | 20% / 20% | 12% / 12% |
| 只从完整任务起点训练 | 20% / 19% | 10% / 9% |

PPO 和消融的 run 在新 bank 第 3 类上只有约 50%：它们基本只学会了在螺母已套上时松手，原 bank 把
这一类算成了约 100%。从头训的 Square run 一开始就用新 bank 选 checkpoint 和评估。其他四个任务
核对过，没有这个问题。

## Square 训练调度与 Drawer 复现

两组实验回答“Square 能不能训得更快”和“合并后的代码能不能复现 Drawer”。两组的结果都比原来的
run 好或相当，所以本文的 Square 和 Drawer 结果都换成了这两组。

- **Square，从头用 20,000 轮的余弦学习率调度**（原来是先训 10,000 轮，再把调度拉长到 20,000 轮
  续训）：两个种子都在第 7,000–8,000 轮突破，第 10,000 轮时测试成功率是 88% 和 87%，原来的两个
  run 同一轮数只有 67% 和 68%。按训练 bank 选出的是 s0 第 14,000 轮（94%）和 s1 第 16,000 轮
  （95%）；原来是 73%（第 18,000 轮）和 95%（第 16,000 轮）。
- **Drawer，用合并后的代码按 README 的配方重训**：选出的是 s0 第 8,000 轮（76%）和 s1 第 4,000 轮
  （90%）；原来的两个 run 是 77% 和 68%。
